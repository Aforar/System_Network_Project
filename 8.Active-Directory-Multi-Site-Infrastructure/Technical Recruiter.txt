# Active Directory Multi-Site and Replication Infrastructure

**Project Category:** IT Infrastructure / Systems Administration  
**Project Type:** Hands-on Enterprise Infrastructure Lab  
**Platform:** VMware Workstation  
**Operating Systems:** Windows Server 2022, Windows 11 Pro  
**Domain:** `adlab.test`  
**Status:** Completed

## Project Overview

Designed, deployed, and validated a two-site Microsoft Active Directory infrastructure simulating a Headquarters (HQ) and Branch office environment.

The project implements a centralized Windows domain with two domain controllers distributed across separate network subnets. It demonstrates practical experience in Windows Server administration, Active Directory Domain Services, DNS, multi-site replication, Group Policy management, and infrastructure troubleshooting.

## Project Architecture

| Component | Configuration |
|---|---|
| HQ Domain Controller | DC-HQ — `192.168.10.10` |
| Branch Domain Controller | DC-BRANCH — `192.168.20.10` |

| HQ Network | `192.168.10.0/24` |
| Branch Network | `192.168.20.0/24` |
| HQ Active Directory Site | HQ-Site |
| Branch Active Directory Site | Branch-Site |
| Virtualization | VMware Workstation |

## Implementation Summary

### Phase 03 — Network Design and Configuration

Designed two separate network segments for HQ and Branch environments. Configured static IP addressing, gateways, and inter-site routing to establish communication between the two networks.

### Phase 04 — Active Directory Deployment

Installed and configured Active Directory Domain Services. Created the `adlab.test` forest and deployed two domain controllers, with DNS and Global Catalog roles.

### Phase 05 — Active Directory Sites and Services

Implemented HQ-Site and Branch-Site, associated the corresponding network subnets, assigned domain controllers to their respective sites, and configured the `HQ-BRANCH-SiteLink` with a replication cost of 100 and a 15-minute replication interval.

### Phase 06 — Client Domain Join and Group Policy

Joined a Windows 11 workstation to the domain. Created Organizational Units, security groups, and test user accounts. Configured domain password and account lockout policies, along with a workstation security baseline.

### Phase 07 — Validation and Troubleshooting

Validated domain authentication, DNS resolution, Active Directory replication, SYSVOL and NETLOGON availability, and Group Policy application. Performed a controlled Branch domain controller shutdown and restart to verify HQ authentication availability for a previously logged-on account and subsequent Branch service recovery.
